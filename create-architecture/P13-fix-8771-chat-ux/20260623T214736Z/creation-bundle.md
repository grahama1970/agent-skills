## Required Fix

The static HTML page at 8771 must be replaced with a page that:

1. **Looks like the real SPARTA Chat** — dark slate theme, Google Sans font,
   material symbols, ChatWell-style message bubbles, proper tool trace panel.
   Reference the existing React components at `pi-mono/packages/ux-lab/src/components/shared-chat/`
   for the correct design.

2. **Auto-injects DEEPGRAM_API_KEY from env** — the Python HTTP server at 8771
   is `python -m http.server` (or a custom script). The HTML should accept the
   key from `window.__ENV__` or similar, and the server should inject it.

3. **Has working microphone button** — `navigator.mediaDevices.getUserMedia` →
   Deepgram WebSocket → transcript → `speech_final` → golden_state_server.

4. **Shows real-time tool traces** — connects to `ws://127.0.0.1:8788/ws`,
   subscribes to `personaplex_tool_trace`, displays `real_*` flags.

5. **Shows Embry's response** — text and/or audio playback from the WS events.

6. **Works without React build** — since `npm run build` is broken, this must be
   a standalone HTML/JS page or use the Vite dev server's output directly.
