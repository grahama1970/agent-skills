# site/ — grahama.co

Next.js (static export) + Tailwind v4, deployed to GitHub Pages via
`.github/workflows/site-deploy.yml`, custom domain grahama.co.

## Design system (roundtable-decided, 2026-08-05)

Light editorial: paper `#FAF8F4`, ink `#16150F`, one oxide-amber accent.
Display face Instrument Serif (self-hosted OFL); body system sans.
**Machine-output rule:** monospace (`.machine`) appears ONLY on text a
program produced — inventory numbers, commit SHAs, paths. Never headlines.
**No fabricated evidence:** no fake traces, no animated counters, no number
that isn't emitted by `scripts/gen_inventory.py`. First-person voice ("I"),
never "we".

**Motion (operator override, 2026-08-07):** the original roundtable set "zero
animation." The operator has since directed two deliberate, structural
exceptions — both physical/real, not decorative theater:
- the capability constellation is a live `d3-force` graph (repulsion +
  collision + drag), matching the persona-dream node graph;
- the search placeholder rotates through real client-style questions;
- the G꜀ mark's subscript c breathes slowly (~5s) as a quiet runtime signal,
  brightening on hover.
Both honour `prefers-reduced-motion` (the constellation settles statically; the
placeholder stops rotating), so the exhibits-not-theater posture still holds for
that audience. No animated *evidence* — counters, traces, fake numbers — remains
banned. Any further motion needs the same explicit operator sign-off.

Direction set by a 4-seat /ask roundtable (webgpt, webclaude, webkimi,
webgemini); packet + receipts in `reviews/grahama-co-roundtable/` and the
tau-dag run `ask-tau-roundtable-webgpt-webclaude-webk-f32d7391fec6`.

## Data flow

- `content.json` — the 10 flagship projects (slug/name/blurb/question/href);
  membership synced from README by `skills/monitor-website`.
- `inventory.json` — generated by `scripts/gen_inventory.py` from the real
  repo (skills, sanity coverage, agents, commit stamp). Regenerate after
  skill changes; the mosaic and hero stats render only from this file.
- Project images: `public/projects/<slug>.webp`, copied from
  `docs/assets/project-cards/`.

## best-practices-react compliance

Interactive elements carry `data-qid` + `data-qs-action` + `title`;
`scripts/verify-data-qid.py` gates CI (exit 1 = not shippable).
`useRegisterAction` is N/A here by documented exception: this is a public
static site with no path to the private ArangoDB runtime; the DOM attributes
carry the full action-ID contract. /review-plan should treat this as
compliant for this app.

## Invariants

- Interactive chrome always renders; no early returns hiding nav.
- No barrel imports.
- The site must never display an inventory figure the generator didn't emit.
