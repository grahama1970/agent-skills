## Design System: NVIS MIL-STD-3009

All components follow the NVIS dark theme with these token namespaces:
- `--nvis-bg-*` — Background surfaces (dark → elevated → surface)
- `--nvis-text-*` — Text hierarchy (strong → label → secondary → dim)
- `--nvis-accent` — Teal accent (#0dd)
- `--nvis-status-*` — Success (green), Warning (amber), Error (red)
