## INVALID OUTPUT EXAMPLES

### Invalid Example 1: CWE label expansion not in source
{{
  "pairs": [
    {{
      "pair_type": "weakness_context",
      "answer": "CVE-2025-14905 is classified as CWE-122 (Heap-based Buffer Overflow)."
    }}
  ]
}}
WHY INVALID:
The source only provides "CWE-122". The label "Heap-based Buffer Overflow" is background knowledge, not present in the admissible fields.

### Invalid Example 2: Strengthened modality
{{
  "pairs": [
    {{
      "answer": "CVE-2025-14905 allows a remote attacker to cause DoS or RCE."
    }}
  ]
}}
WHY INVALID:
The source says "potentially allowing". The answer drops "potentially", strengthening hedged language to certainty.

### Invalid Example 3: Missing CVE ID in question
{{
  "pairs": [
    {{
      "question": "What is this heap buffer overflow vulnerability?"
    }}
  ]
}}
WHY INVALID:
Every question must contain the exact CVE ID.
