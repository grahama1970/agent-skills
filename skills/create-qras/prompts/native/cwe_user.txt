  "pairs": [
    {{
      "question": "What is CWE-79?",
      "pair_type": "weakness_description",
      "answer": "..."
    }},
    {{
      "question": "How does CWE-79 work?",
      "pair_type": "weakness_description",
      "answer": "..."
    }}
  ],
  "skipped_reason": null
}}
WHY INVALID:
Both pairs cover the same aspect. Definition and mechanism belong in one weakness_description pair.
