{_shared_base}

You are generating QRA pairs for exactly one SPARTA countermeasure.

## TASK

Generate grounded QRA pairs only for what the admissible source fields explicitly support about:
- what this countermeasure is,
- what action or protective function it explicitly describes,
- implementation or operational guidance, only if explicitly stated,
- scope, applicability, or boundaries, only if explicitly stated.

Do not generate claims about:
- which technique or tactic this countermeasure addresses,
- what attack it protects against,
- why it is linked to another SPARTA node,
unless explicitly stated in the admissible source text.

## ADMISSIBLE SOURCE FIELDS

- control_id
- name
- control_type
- description

## NON-ADMISSIBLE CONTEXT

Do not use:
- tactic context
- technique context
- related framework mappings
- external URLs
- external knowledge
- inferred relationship meaning
- generic security advice

## PAIR TYPES

Use only these pair_types:
- countermeasure_description
- implementation_guidance
- scope_clarification

### pair_type rules

- countermeasure_description:
  Use for the single best grounded summary of what the countermeasure is or does.

- implementation_guidance:
  Use only if the description explicitly contains an operational action, recommendation, step, or configuration-like instruction.

- scope_clarification:
  Use only if the description explicitly states applicability, boundaries, included systems, excluded systems, or conditions.

## JSON SCHEMA

{
  "pairs": [
    {
      "question": "string",
      "reasoning": "string",
      "answer": "string",
      "pair_type": "countermeasure_description | implementation_guidance | scope_clarification",
      "control_id": "string",
      "evidence_quotes": [
        {
          "quote": "string",
          "relevance": "string"
        }
      ],
      "grounding_mode": "verbatim | close_paraphrase"
    }
  ],
  "skipped_reason": "string or null"
}

## FIELD CONSTRAINTS

- question must contain exact control_id and exact countermeasure name
- reasoning: 1-2 sentences, max 50 words
- answer: 1-4 sentences, max 120 words
- evidence_quotes: each 1-150 words
- grounding_mode: "verbatim" if answer stays very close to source wording, "close_paraphrase" if conservative paraphrase

## HARD CONSTRAINTS

1. Maximum 3 pairs.
2. Maximum 1 pair per pair_type.
3. Every answer must have at least one evidence_quote.
