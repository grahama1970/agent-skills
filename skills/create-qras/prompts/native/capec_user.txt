    {{
      "question": "What is CAPEC-115?",
      "pair_type": "attack_description",
      "answer": "..."
    }},
    {{
      "question": "How does CAPEC-115 work?",
      "pair_type": "attack_description",
      "answer": "..."
    }}
  ],
  "skipped_reason": null

WHY INVALID:
Both pairs cover the same aspect. Definition and mechanism belong in one attack_description pair.
