Watch Realtime Identity Memory Loop P1

Movies are the test case for AO video memory: realtime tracking proposes observations, domain references verify identity, and bounded traces persist through memory for later recall.

Primary Object

Tracked Evidence Trace

A time-bounded track observation with frame, crop, transcript, source refs, identity status, and memory persistence pointers.

ML Runtime

YOLO + ByteTrack

Realtime track ids stream live; identity verification samples at a bounded cadence such as 5 FPS.

Domain Memory

References Before Ingest

Movies hydrate cast/character references; drones and restricted streams require source manifests.

Fail Closed

No Unsupported Identity

Search results and detector labels are candidates only. Ambiguous identity stays inconclusive or needs human review.

Pipeline Contract

/intentClassify query vs command before retrieval.
extract-entitiesFind characters, assets, spans, and time ranges.
/recallQuery Watch memory via ArangoSearch and Qdrant pointers.
track verifyCompare track crops, references, and row text.
case anchorCreate evidence case only when bounded evidence requires it.
answerAnswer, clarify, or deflect from grounded evidence.

Storage

Qdrant + Jina

Multimodal/text embeddings for reference images, crops, segments, and row text.

Graph

Arango Metadata

Entities, assets, track observations, cases, and Qdrant point ids. No raw vectors.

Case

watch_evidence_cases

Anchored by entity_ids plus time_range, with verdict and failure code separation.

UI Contract

Realtime Overlay Events

The modal consumes live track events; UI polish is downstream, not the architecture task.

Acceptance Bar

  • Approved reference fixtures and deterministic embedding ids exist before identity support.
  • Track observations link to segment, frame, crop, transcript, and source refs.
  • Memory write and recall proof exists before user-facing recall claims.
  • Static overlay screenshots are not accepted as realtime tracking proof.
