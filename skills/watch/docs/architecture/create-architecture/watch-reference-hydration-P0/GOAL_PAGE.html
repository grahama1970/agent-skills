Target model for WebGPT creation: make character/object identity verification a fail-closed pipeline that joins movie-domain references, real-time ML tracks, multimodal embeddings, graph metadata, and `$memory recall`.

Master Flow

1. Asset
Cinema, drone, RTSP, YouTube.
2. Reference
Auto-hydrate movie cast refs or require source manifest.
3. Track
YOLO/ByteTrack stream observations and crops.
4. Verify
Compare crop, frame, text, transcript, reference package.
5. Persist
Memory records, Arango metadata, Qdrant pointers.
6. Recall
Find all segments with entity traces and case anchors.

Required Fail-Closed Rule

Detector labels, Brave snippets, and movie-domain priors are not enough to mark a row as IDENTITY_SUPPORTED. A supported identity needs a bounded observation, an approved reference package, a comparison score/evidence record, and persistence that can be recalled.
