## Inspection Commands

```bash
python3 skills/watch/scripts/build_realtime_tracking_upsert_payloads.py
```

```bash
python3 - <<'PY'
import json
from pathlib import Path
out = Path('skills/watch/docs/architecture/generated/bad_santa_marcus_0248_upsert_payloads')
forbidden = {'embedding', 'embeddings', 'vector', 'vectors', 'dense_vector'}

def scan(value, path='$'):
    if isinstance(value, dict):
        for k, v in value.items():
            if k in forbidden:
                raise SystemExit(f'forbidden_vector_key {path}.{k}')
            scan(v, f'{path}.{k}')
    elif isinstance(value, list):
        if len(value) > 8 and all(isinstance(x, (int, float)) for x in value):
            raise SystemExit(f'forbidden_numeric_vector {path}')
        for i, v in enumerate(value):
            scan(v, f'{path}[{i}]')

for path in sorted(out.glob('upsert_*.json')):
    payload = json.loads(path.read_text())
    assert set(payload) == {'collection', 'documents'}
    assert payload['documents']
    scan(payload)
    print('payload_ok', path.name, payload['collection'], len(payload['documents']))
PY
```

## Acceptance Rationale

The payload set is accepted as request-shape proof because it is generated by an
offline builder from the accepted manifest and deterministic tracker event log.
It confirms the Watch memory write boundary: Arango-bound records contain
metadata and Qdrant pointers, while vector material remains outside the Arango
documents.

## What This Does Not Prove

- It does not prove live memory writes.
- It does not prove `/recall` returns the records.
- It does not prove Qdrant vector writes.
- It does not prove live tracker inference or UI overlay rendering.
- It does not prove Marcus is visually present.
