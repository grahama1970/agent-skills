# Reference implementations

The skill architecture was informed by these public projects:

- `disler/fixing-smartass-opus-5`: target visual vocabulary and self-contained CSS SVGs.
- `arikusi/nakkas`: declarative SVG configuration, previews, filmstrip sampling, and audits.
- `cduck/drawsvg`: Python-native programmatic SVG generation.
- `csthink/dashmotion`: deterministic layout and structural verification patterns.
- `maxwellito/vivus`: normalized stroke drawing concepts.
- `collectioneur/readme-aura`: generated README assets and custom-font workflows.

This skill does not vendor their source code.
