# Path-B text-channel probe (arc_state specificity) — 2026-07-25

Method: one fixed dream residue ("the door stayed shut and no one came when I
called."), same prompt, three ledger conditions, generated through /tau.

- REAL arc_state:  "I'll keep the door shut for now; if you heard me, don't make me explain it."
- EPOCH-0 (empty): "I woke with my hand still lifted, and I'm not ready to lower it yet."
- SHUFFLED control (opposite traits): "I'm banging louder now—someone come in, anyone, I don't want to be left talking to a shut door."

Result: the spoken line tracks arc_state CONTENT, not just its presence. Real ->
guarded-Embry (distance + wanting witness without asking); empty -> neutral;
shuffled -> the shuffled persona (loud/demanding). The shuffled != real result is
the specificity signal that kills the "any extra context changes wording" confound.

Bound (honest): n=1 per condition, single residue, author-judged (not blind).
Suggestive, NOT proof. Full claim needs K samples + blind classification + the
acoustic channel (fixed-probe cycle-0 vs cycle-N WAVs, ABX).
