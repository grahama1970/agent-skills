Q2 — Signal vs. redundancy in the judge panel First, a disclosure that matters: one of the two seats was me (Claude), and this bundle now shows me the answer key. Any re-run must use fresh sessions with no access to this thread, or the claude seat is contaminated. How to tell signal from redundancy: agreement alone can't do it — you need judges that can disagree and see where they do. Three moves: Deliberate diversity along failure modes, not vendors-for-show: 4–5 seats spanning model families (Claude, GPT, Kimi, one open-weights e.g. Llama/Qwen) and prompt framings — at least one seat judging from a rubric-free "describe the disposition freely" prompt, coded post hoc, so all seats aren't anchored to the same disposition vocabulary. If a shared vocabulary is doing the work, free-description seats will diverge. Bias controls: position swap every packet (A/B order randomized per seat, per 2606.19544); add ~15% catch trials — duplicated deliveries (should yield "indistinguishable") and swapped-label duplicates (should flip the grounding call). A judge failing catch trials is discounted, not averaged in. Statistic: Krippendorff's α (handles >2 raters, nominal categories, missing data) on distinguishability and on grounding separately. α ≥ 0.67 tentative, ≥ 0.8 credible. Crucially, also report per-item entropy: healthy panels show high agreement on clear items and genuine splits on hard ones. Uniform near-1.0 agreement across all items including the deliberately hard catch trials is the redundancy signature — that's "one verdict bought five times." Q3 — The compute-matched M-arm contract The tightrope: give the M-arm equal LLM compute without letting it dream. Contract: Same model, same token budget, same output schema (tone/pace/emphasis_tag + weight formula) as the D-arm. Input restriction: raw memory records only — no dream artifacts, no valence-conflict seeds, no graph traversal, no cross-memory edges, no cross_persona_hooks. The M-arm sees each cycle's memory triple verbatim and nothing derived. Operation restriction (the anti-mini-dream clause): the prompt instructs summarization/affect-mapping of what the memories state, and explicitly forbids counterfactual elaboration, imagined scenes, perspective-taking of other personas, or synthesis of content not literally present. This is the operative distinction: dreaming = generative recombination + ToM; M-arm = extractive affect reading. Enforcement, not just instruction: post-hoc audit each M-arm output for novel entities/events absent from the source memories (a cheap NER/string-grounding check). Any M-output containing non-source content is regenerated; log the regeneration rate — if it's high, the boundary is leaking and D≈M results are suspect. Symmetric lineage: record M-arm prompts/outputs with the same provenance schema as dreams so the panel packets are structurally indistinguishable (protecting blinding). The claim then sharpens to: "recombinative dreaming adds affect nuance beyond extractive LLM affect-reading of the same memories at matched compute" — which is the claim actually worth having. Q4 — Is rated disposition the right terminal proof? It's the right intermediate proof and the wrong terminal one. "Measurably nuances the voice" is satisfied by the perception panel; but the operator's framing — the consumer is an agent — implies the affect should do something to the consuming agent, not just be describable by it. The ToM caution (2603.28925) cuts here too: an agent-judge's disposition label is an attribution, dissociable from any functional effect. Cheapest downstream-utility task: a calibration-sensitive decision task. A consumer agent receives Embry's voice-composed answer to an ambiguous operational question (e.g., "is this fault safe to defer?") in two variants with identical propositional content (safety rule preserved) — one D-conditioned tone, one M-conditioned. The consumer must then choose a follow-up action from a fixed menu (proceed / verify / escalate) and state confidence. Measure whether tone condition shifts action choice or confidence distribution. ~13 cycles × 2 conditions × 3 consumer seats is an afternoon of runs. If dream-tone shifts consumer behavior where memory-tone doesn't (or shifts it more appropriately given the memories), that's agent-utility, not just agent-legibility. It also stress-tests the safety rule: any content drift between variants is a gate failure caught for free. POSITION SUMMARY Current results show legibility of dream affect vs. a deterministic baseline, not superiority over fair LLM memory-reading; the 8/13 grounding figure is confounded. Order of work: fair M-arm first, then bias-audited multi-seat panel — precision before scale is wasted on a biased contrast. Panel credibility needs engineered disagreement: 4–5 diverse seats, position swaps, catch trials, Krippendorff's α with per-item entropy; and fresh judge sessions (the prior claude seat — me — is now unblinded). Compute-matched M-arm = same model/budget/schema, memories-only input, extractive-only operation, enforced by novel-content audit. Terminal proof should graduate from rated disposition to a consumer-agent behavior shift under content-identical, tone-varied deliveries.
