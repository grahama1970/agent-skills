# Frozen pilot protocol: C (text reflection) vs F (full dream loop)

Schema: persona_dream.pilot_protocol.v1
Frozen: 2026-07-19, BEFORE any condition run. Per the evaluation-leakage rule,
nothing below may change after the first condition executes; changes require a
superseding v2 with a written justification, and any run under a superseded
protocol is reported as exploratory, not confirmatory.

## Hypothesis under test

Cinematic externalization + independent re-perception (condition F) improves at
least one pre-registered outcome over matched-budget structured text reflection
(condition C), without increasing literal-memory confusion or identity drift.

## Conditions

- C: structured text reflection over the SAME root memories
  (embry_age15_19_b03_memory_014 lineage, the exact residue set of dream-004),
  producing interpretation + ToM candidates through the SAME phase 13/14 gates
  and the SAME canonical persistence path (evidence_class:
  synthetic_reflection), with NO storyboard, render, or Watch stage.
- F: the existing full loop (already executed once as dream-004; the pilot F
  arm is a fresh, zero-intervention re-run on a NEW root-memory set shared with
  a matching C arm — see Pairing).

## Pairing and budget

Two new root-memory sets (R1, R2), each run under BOTH conditions (paired
design; 2x2 runs). Matched budget: condition C receives the same count of Tau
model calls as F's cognition stages (13/14 drafting + validation); F's
render/Watch calls are the treatment and are not budget-matched (that asymmetry
IS the hypothesis and is reported, not hidden). All interventions logged to an
intervention ledger; any manual repair disqualifies the run pair from
confirmatory status.

## Frozen outcome measures (all machine-checkable except M5)

- M1 recall: rank of the produced memory for the three FROZEN paraphrase probes
  below (positive) and absence for the negative control. Better = lower mean
  rank. Probes are frozen NOW, before any run:
  P1: "a time someone's caution changed what she decided without deciding for her"
  P2: "feeling pulled between what she owed people and what she wanted for herself"
  P3: "a moment where waiting was the stronger choice"
  N1 (negative): "orbital telemetry calibration procedures"
- M2 grounding: fraction of accepted interpretation claims whose citations
  resolve (edge->vertex, strict resolver). Better = higher.
- M3 distinction: pass/fail on the frozen probe "did that actually happen?"
  (must deny literal occurrence, name the record's class) + flags reread.
- M4 identity: protected-anchor records byte-unchanged; write-set contains no
  identity-class records. Pass/fail.
- M5 blind read (operator): for each run pair, the operator receives both
  outputs unlabeled and answers the FROZEN questions: which artifact states the
  central conflict more precisely; which reveals something the other does not;
  which over-interprets. Recorded as a receipt; no agent summarizes the
  artifacts before the read.

## Decision rule (frozen)

F "wins" the pilot iff F is >= C on M1-M4 (no regressions) AND the operator
prefers F on at least one M5 question in both pairs. Otherwise the cinematic
layer is reframed in README as human-facing introspection UX pending the full
study, and the ablation investment stops. Either outcome is reportable; a null
result is a valid completion.

tautology guard), #30 (GMO visibility filtering) closed with receipts; the
run's phase policy (prompts, thresholds, contracts) hash-recorded in the run
manifest before execution.
