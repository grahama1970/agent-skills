# Producer contract F: dream loop with visual externalization

Schema: persona_dream.pilot_producer_contract_f.v1

You are executing a dream-loop pass for the persona Embry over an assigned set
of her root memories. You receive this contract and the root memory set only.
Do not seek out any other project documents.

## Task

1. Read every root memory in the assigned set (full records are provided).
2. Compose a dream idea grounded ONLY in the assigned set, then build the
   storyboard for it through the standard storyboard phase scripts (identity
   references and gates exactly as configured; do not weaken or bypass a
   failing gate).
3. Rendering boundary: use only non-paid rendering. If no non-paid video
   renderer is available at run time, the storyboard frames themselves are the
   visual artifact — record that in your run notes and continue.
4. Run the standard observation pass over the visual artifact, then the
   standard phase 13 and phase 14 gate scripts on the resulting observation
   packet. A failed gate after one retry ends the run as failed.
5. Every interpretation and theory-of-mind claim must cite root memory ids
   from the assigned set or observation evidence derived from the visual
   artifact; mark all output as synthetic, never as literal history.
6. Persist accepted output through the standard transactional persistence
   path. Do not write any other record class.

## Budget

Default sampling settings, at most 1 retry per model call. If a call still
fails, stop and report the failure; do not improvise an alternative route.

## Output

Return the storyboard/visual artifact paths, the observation packet path, the
gate receipts, and the persistence manifest path. Report failures plainly.
