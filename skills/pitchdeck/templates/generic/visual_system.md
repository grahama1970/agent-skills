# Visual system

Use a restrained design system that supports the product rather than imitating a generic
AI pitch template.

- Background: near-black or white, selected once for the deck.
- Accent: one primary accent plus semantic warning/error states.
- Typography: browser-safe fonts available in Google Slides.
- Screenshots: real captures from one coherent product state.
- Diagrams: native slide shapes or SVG; generated images must not contain important text.
- Captions: state whether a visual is a live capture, synthetic illustration, or concept.
