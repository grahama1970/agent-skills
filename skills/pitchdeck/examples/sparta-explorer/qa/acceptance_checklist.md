# Sparta deck acceptance checklist

## Source state

- [ ] `SPARTA_PUBLIC_ROOT` and `SPARTA_ROOT` resolve to the intended checkouts.
- [ ] README source hashes/commits are recorded.
- [ ] Demo preflight passes for the exact private commit shown.

## Public deck

- [ ] Exactly 12 public slides.
- [ ] Only `sparta-public-readme` appears in source references.
- [ ] No private receipt paths or unqualified mutable counts.
- [ ] Synthetic F-36, candidate/compliance-credit, and human-authority boundaries remain.
- [ ] Threat Matrix, Global Posture, and Sparta Chat captures form one coherent set.

## Private appendix

- [ ] Exact counts retain date, population, artifact, and non-claim.
- [ ] Response-route and deployment gaps remain explicit.
- [ ] Prepared-host preflight language names exact-commit binding.
- [ ] Appendix is excluded from the distributed public export.

## Visual and delivery

- [ ] PDF/contact sheet reviewed at normal presentation scale.
- [ ] Google Slides import inspected slide by slide.
- [ ] No meaning-bearing screenshot is cropped or stretched.
- [ ] Speaker notes preserve source and claim IDs.
