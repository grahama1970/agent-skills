# monitor-website local brand guard — grahama.co

Canonical site brand file: `site/BRAND.md`.

Use this guard when `$monitor-website` audits, updates, reviews, or repairs
grahama.co.

## Operator intent

grahama.co should be discovered, not optimized into a cold value proposition. It
should be bespoke, entertaining, honest, and unmistakably Graham. It should not
look like any other AI/R&D-tech site.

## What monitor-website may fix

- stale counts, proof displays, or generated-surface drift;
- wrong canonical repository links;
- missing alt text, accessible names, qids, or source labels;
- public/private boundary confusion;
- broken discovery paths.

## What monitor-website must not do by default

- normalize the site into a services/industries/contact funnel;
- remove weirdness merely because a cold visitor might not understand it;
- flatten Dream, creative media, voice, DARPA, and formal methods into a neat
  enterprise narrative;
- imitate Straive, Palantir, or generic R&D-tech category language;
- rewrite human prose unless a human-authored source changed.

## Review question

For any proposed site change, ask:

> Does this make grahama.co more Graham while keeping facts exact?

If not, do not apply it.
