## `packages/ux-lab/sim/cdp-harness.cjs`

A reusable, raw-CDP (no Puppeteer) interaction driver for UX Lab projects.

### Architecture
- **Raw WebSocket** — mirrors the `cdp-verify.cjs` pattern; connects to Chrome's `/json` endpoint, opens the debugger URL directly
- **Runtime.exceptionThrown capture** — all JS errors from the page are accumulated in `getRuntimeErrors()`
- **Structured JSON returns** — every method returns `{ ok: boolean, result? }` or `{ ok: false, error: string }`
