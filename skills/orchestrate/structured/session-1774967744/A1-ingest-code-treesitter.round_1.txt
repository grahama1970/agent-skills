Key design choices:

- **`--treesitter` flag** on the `rescan` command, default `False` so existing behavior is unchanged
- **Calls `run.sh scan <dir>`** per configured codebase, parses the JSON output (skipping the status line before the array)
- **Tags**: `["codebase", "symbol", "<kind>", "<name>", "<file_stem>"]` exactly as specified
- **Memory storage**: uses the existing `_learn()` → `_learn_http()` path which already talks to the Unix socket at `/run/user/1000/embry/memory.sock`
- **600s timeout** on the subprocess since large codebases can take a while
- **Graceful fallback**: if treesitter skill isn't found or scan fails, prints a warning and continues
