6. Failure, Escalation, and Remaining Risk

Retry exhaustedWrite {task_id}.failure-bundle.json and {task_id}.interview-request.json.
Dependents blockedDownstream tasks become DEPENDENCY_FAILED; no false green execution.
Interview is opt-inORCHESTRATE_ENABLE_INTERVIEW_ESCALATION=1; CI/headless never blocks by default.
Remaining risk: opaque commands can lie about local-only behavior. Metadata is required, but reviewers must still audit what the script actually does.
