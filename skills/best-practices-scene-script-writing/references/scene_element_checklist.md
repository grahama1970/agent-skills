# Scene element checklist (per beat)

For each element class, the questions a beat description must answer. Derived
from persona-dream's Panel Continuity Gate hard rejects, generalized.

## Characters

| Question | Example answer |
|---|---|
| Primary action (one, physics verb) | "leans in, tapping the table twice" |
| Environment contact | "her ponytail lifts in the storm wind" |
| Post-action state | "then stills, mouth closed, watching him" |

## Props (each highlighted prop)

| Question | Example |
|---|---|
| Material state | "porcelain teapot, glaze reflecting lightning" |
| Behavior or stated stillness | "lid rattles faintly with the table tap" |
| Interaction source | wind / touch / vibration / heat / none-with-reason |

## Environment

| Question | Example |
|---|---|
| Place, specific | "gothic void-world terrace, flagstones and iron rail" |
| Time / light condition | "perpetual storm dusk" |
| One active force | "wind pushing left-to-right across frame" |
| Force's visible effect | "umbrella fabric shivers; steam tears sideways" |

## Weather

| Question | Example |
|---|---|
| Named condition | "dry electrical storm, no rain" |
| Rhythm | "lightning strobes every few seconds" |
| Touches whom/what | "overexposes faces for single beats" |

## Creatures / background life

| Question | Example |
|---|---|
| Gait + speed | "drags its bulk slowly" |
| Attention | "ignoring the patio" |
| Contact/friction | "claws scraping stone, dust drifting" |
| Entry/exit | "vanishing behind a spire" |

## Lighting

| Question | Example |
|---|---|
| Source(s), in-world | "laptop glow + storm sky + lightning" |
| Behavior | "glow flickers with the display; lightning strobes" |
| Constancy across beats | same sources, same key direction, every beat |
| Hardness matches tone | soft glow for intimacy, hard strobe for menace |

## Sound (when the beat is audio-bearing)

| Question | Example |
|---|---|
| What is audible | "distant creature calls under the wind" |
| Tied to visible source | thunder follows the visible lightning |

## Anti-patterns

- Noun lists without verbs ("table, umbrella, teapot, laptop").
- Weather that touches nothing.
- "Cinematic, atmospheric, epic" doing the work verbs should do.
- Identity prose (hair color, armor detail) when reference images carry it.
- Ten behaviors at one word each instead of three at full physical detail.
- Stillness by omission (unstated = model's choice, usually frozen).
