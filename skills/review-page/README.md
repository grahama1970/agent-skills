# review-page skill

`review-page` standardizes WebGPT-centered page reviews for UI/product surfaces.

It creates:

- `REVIEW_PACKET.md` for WebGPT
- `report.html` for the human
- `review.json` for gates/automation
- screenshot gallery/contact sheet
- benchmark web-research prompt
- optional `test-interactions` manifest templates

Use it when a project agent would otherwise bespoke a page review, over-trust text-only WebGPT, or hide failure behind green dashboard labels.
