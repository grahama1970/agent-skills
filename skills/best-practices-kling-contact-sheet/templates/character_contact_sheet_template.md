# Character Contact Sheet Template

Use 2–4 separate images for the Kling Element. Use the contact sheet only as a human-facing review board.

## Required references

```text
01_main_front_full_body.png
Purpose: Main identity anchor.
Requirements: front-facing, full body, neutral readable pose, face visible, outfit unobstructed.

02_three_quarter_full_body.png
Purpose: Shows facial structure, body depth, hair volume, silhouette.
Requirements: same outfit, same hairstyle, same body proportions.

03_side_or_back_view.png
Purpose: Shows hair shape, back/side outfit construction, profile, footwear.
Requirements: match all fixed details; avoid changing scar/parting/accessory side.

04_face_or_detail_closeup.png
Purpose: Locks face, eyes, makeup, scars, jewelry, fabric texture, signature accessory.
Requirements: clear crop, no heavy shadow, no alternate design.
```

## Common character problems

- Too many outfits: create separate Elements per outfit.
- Face hidden: add a clean front close-up.
- Identity mark flips sides: fix references before upload.
- Background gets copied into shots: add it to `Ignore` or use plain references.
- Model creates duplicates: upload separate images instead of the grid.
