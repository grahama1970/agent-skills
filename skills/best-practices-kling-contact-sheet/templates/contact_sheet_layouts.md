# Contact Sheet Layouts

These layouts are for human review. Export each panel separately for Kling Element upload whenever possible.

## 2-image minimum Element layout

```text
+-------------------------------+-------------------------------+
| 01 MAIN / FRONT / HERO        | 02 SUPPLEMENTARY ANGLE        |
| Identity anchor               | Different angle or details    |
+-------------------------------+-------------------------------+
```

## 3-image Element layout

```text
+-------------------------------+-------------------------------+
| 01 MAIN / FRONT / HERO        | 02 SUPPLEMENTARY ANGLE        |
| Identity anchor               | Depth / side / top / layout   |
+-------------------------------+-------------------------------+
| 03 DETAIL / SCALE / MOOD      | NOTES                         |
| Close-up or important lock    | Do not change / ignore        |
+-------------------------------+-------------------------------+
```

## 4-image recommended Element layout

```text
+-------------------------------+-------------------------------+
| 01 MAIN / FRONT / HERO        | 02 THREE-QUARTER / ALT ANGLE  |
| Identity anchor               | Depth and silhouette          |
+-------------------------------+-------------------------------+
| 03 SIDE/BACK/TOP/SCALE        | 04 DETAIL / CLOSE-UP / MOOD   |
| Construction and scale        | Critical details              |
+-------------------------------+-------------------------------+
```

## Labeling rules

- Put labels outside the subject, preferably in a small margin.
- Do not place arrows, captions, or grid lines over the face, prop, or landmark.
- Use boring labels: `front`, `3/4`, `side`, `detail`, `scale`, `wide`, `lighting`.
- Avoid decorative typography that could be interpreted as part of the asset.

## Export rule

The contact sheet may be named:

```text
AssetName_contact_sheet_review.png
```

The actual Kling-ready images should be separate:

```text
01_main_front_or_hero.png
02_three_quarter_or_alt_angle.png
03_side_back_top_or_scale.png
04_detail_closeup.png
```
