# Contact Sheet Audit

Use this when reviewing an existing contact sheet.

## Fast audit scoring

Score each section 0–2:

```text
Image count:       0 = too many/too few, 1 = usable, 2 = ideal 2–4
Main reference:    0 = unclear, 1 = okay, 2 = strong front/hero
Angle coverage:    0 = redundant, 1 = partial, 2 = useful alternate views
Detail coverage:   0 = missing, 1 = some, 2 = critical details clear
Consistency:       0 = contradictory, 1 = minor drift, 2 = stable identity
Background:        0 = confusing, 1 = usable, 2 = clean or intentional
Labels/layout:     0 = intrusive, 1 = acceptable, 2 = unobtrusive
Description:       0 = missing, 1 = generic, 2 = specific locks + ignore
```

14–16: Ready.
10–13: Usable after minor cleanup.
6–9: Rebuild key references.
0–5: Not model-readable enough.
