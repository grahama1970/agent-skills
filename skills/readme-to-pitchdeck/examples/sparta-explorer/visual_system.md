# Sparta Explorer deck visual system

## Palette and typography

- Near-black/navy field supporting existing Explorer dark-mode captures.
- Cyan for active evidence lineage and primary emphasis.
- Teal for governed/connected state.
- Amber for incomplete, stale, or needs-attention states.
- Red only for explicit failed gates or blockers.
- Muted violet for synthetic/demo context.
- Arial for narrative; Courier New only for IDs, hashes, and route states.

## Reusable archetypes

1. Cover with product capture.
2. Big statement and supporting evidence rows.
3. Three-boundary cards.
4. Native decision-thread flow.
5. Full-width screenshot with three callouts.
6. Dated proof cards.
7. Working/integration/open roadmap.
8. Three-path collaboration ask.

## Asset rules

- Recapture Threat Matrix, Global Posture, and Sparta Chat from one preflighted commit.
- Keep capture date/commit metadata in notes or caption.
- Treat the Embry OS image as conceptual, not product proof.
- Rebuild flow diagrams as native shapes.
- Do not use generated fake UI.
- Keep the current QRA screenshot private or recapture after the named defect is repaired.
