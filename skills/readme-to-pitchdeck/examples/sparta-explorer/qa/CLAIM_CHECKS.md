# Sparta claim checks

Fail review when the deck introduces any of these without a precise source and qualifier:

- all surfaces use one evidence model;
- all QRAs are evidence-bound;
- all Console responses use the governed route;
- current mutable counts without date, population, and source artifact;
- turnkey or clean-machine deployment;
- operational F-36 data;
- Lockheed Martin deployment, approval, or endorsement;
- accreditation, certification, ATO, or production-readiness claims.

Check that public slides cite only `sparta-public-readme`. Private receipt detail belongs
in `deck.private-appendix.yaml`.
