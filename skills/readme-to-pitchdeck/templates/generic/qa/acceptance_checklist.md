# Acceptance checklist

## Source and claims

- [ ] Every visible claim has a source reference.
- [ ] Candidate claims were approved, rejected, or explicitly retained as draft.
- [ ] Public slides do not reference private sources, claims, or assets.
- [ ] High-risk status/proof claims include required qualifiers.
- [ ] Mandatory non-claims are bound to at least one slide.

## Slides

- [ ] One message per slide.
- [ ] Editable text and shapes, not full-slide screenshots.
- [ ] Required assets exist and are current.
- [ ] Meaning-bearing screenshots are not cropped or stretched.
- [ ] Speaker notes retain source and claim identifiers.

## Proof

- [ ] `build-receipt.json` exists.
- [ ] `verify_receipt.json` has no errors.
- [ ] PDF and contact sheet were reviewed.
- [ ] Google Slides import was inspected for font substitution and layout drift.
