Findings

F-001 Summary cards are not evidence-backed

Status
Needs Changes
Evidence
S-001 shows summary cards before evidence; S-002 does not bind states to validation records.
Rationale
The surface presents status before exposing the source records or predicates that justify status.
Impact
Readers may treat an unverified summary as operational truth.
Owner
Report surface designer / project-agent UI implementer.
Acceptance Check
Every top-summary status maps to a finding ID and source artifact.
Evidence note: This example intentionally labels sources as placeholders so it does not imply verification.

F-002 Missing source-of-truth inventory

Status
Blocked
Evidence
The report contains no explicit source table listing files, logs, screenshots, APIs, or validation artifacts.
Rationale
Without source inventory, the reader cannot distinguish verified claims from assumptions.
Impact
The report cannot support reliable implementation planning.
Owner
Report author / review agent.
Acceptance Check
The report contains a source inventory with source IDs referenced by findings.
