# AI-Generated-Template Residue


Added after auditing a real evidence-first practice site (grahama.co) that a
reviewer called "AI-generated," where a live design roundtable + code
verification showed the diagnosis was half right in a specific, instructive way.

### Separate surface tells from structural tells

The signifiers people first name — dark ground, one warm accent, monospace meta,
rounded metric boxes, an amber-on-slate palette — are **surface tells**. They are
cheap to change and their absence does **not** prove bespoke. The load-bearing
tells are **structural**, and they survive any recolor:

- uniform section chrome (identical eyebrow/number on every section);
- an identical card grid for N items that deserve unequal weight;
- **one global type setting** used as a design system rather than set per instance;
- systematic numbering and taxonomies presented as the only container;
- **monospace on human-written labels** (mono should mark program output only —
  mono-on-everything reads as a dashboard).

AUDIT rule: when a design is called "generated," score the structural tells under
G6/G7 first. A change that only touches surface tells (swap the accent, add grain)
is **NOT_TESTED** for distinctiveness — it has not addressed the residue.

### Structural distinctiveness ranks above decorative distinctiveness

A compound-grid asymmetry where no two sections share a column structure, unequal
content weights, journal-forward lockups, and margin/marginalia do more for
authorship than any amount of ornament. Prefer editing the **information
architecture** ("these ten items need not be ten identical cards — some are an
essay, some a diagram, some a link") over adding decoration. Decoration on top of
uniform IA is lipstick; it fails G6.

### Craft integrity — no fabricated imperfection (G15)

"Hand-made" must never mean **simulated** hand-made. On any site whose value is
evidence and proof, faked craft is a self-inflicted wound:

- No code-jittered "hand-drawn" lines, random rotations, torn-paper edges, or
  distress filters generated to *look* authored. Imperfection ships only if it is
  genuinely authored or scanned.
- **Machine-output surfaces stay pristine** — SHAs, counts, receipts, and any
  program-emitted value never receive decorative imperfection. Imperfection may
  live on the container, never on the evidence.
- This extends the evidence-culture rule ("no fabricated numbers") to aesthetics:
  no fabricated *craft*.

### Trust-integrity for rigor-positioned brands

For a proof/compliance/defense-adjacent practice, looseness has a cost the gates
must weigh: too much organic irregularity subconsciously undermines the rigor
message. Handmade quality must read as **care, not sloppiness**. Variation needs a
**family resemblance** across sections, or the site reads as an effects showcase
rather than one practice. Whimsy that would read as *costume* on the buyer who
matters (a procurement or security reviewer) fails G1 (user/content fit).
