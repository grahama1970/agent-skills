Primary Question

Can Embry sound live and conversational while still obeying current-turn memory, evidence, and compliance routing constraints? PersonaPlex owns voice and live interaction. Memory, search, and evidence-case products own factual authority.

Memory Contract Reassessment

Route Authority

  • $memory intent is the current-turn front door.
  • $memory answer, clarify, and deflect are structured products.
  • The wrapper must not invent local answerability or ambiguity thresholds.

Recall Contract

  • Recall returns items, not results.
  • Proof reads confidence plus scores.bm25, scores.dense, and scores.graph.
  • Persona recall must be question-shaped and scoped, for example persona:embry.

Persistence Contract

  • /upsert writes canonical Arango documents.
  • Do not write inline vector arrays into Arango.
  • Qdrant owns semantic vectors; Arango stores pointer metadata and text hashes.
Memory project caveat: SPARTA compliance answer-from-evidence-packet, multi-turn judge state, QRA conflict gates, and disjoint-technique live E2E are still known gaps. PersonaPlex must fail closed around those gaps rather than smooth them over.

Target Runtime Flow

03 Final TurnDeepgram `speech_final` creates a new `turn_id`.
04 Gate ClosedCancel or fence stale work; clear injection state.
05 Memory IntentCurrent transcript decides route, tools, entities.
06 GroundingRecall, search, clarify, deflect, answer, evidence case.
07 ReleaseInject compact context, open only for active turn, write receipts.

Required Invariants

Turn Safety

  • Every user turn has a monotonic `turn_id`.
  • Every callback verifies the active `turn_id` before mutating state.
  • Stale tasks cannot enqueue, open the gate, write receipts, or update memory.

Authority

  • Current `$memory intent` is the only routing authority.
  • Historical tool calls are context only.
  • Compliance uncertainty fails closed.

Persistence

  • `conversation_history` is canonical.
  • Summaries and voice projections are rebuildable.
  • Audio artifacts are stored by hash/path and linked from the turn.

Acceptance Gates

Native Cache Gate

Create native `.pt`, replay in a fresh process, and write valid WAV/text/runtime receipts.

Single-Turn Research Gate

Show intent, recall/search, route product, gated injection, and grounded PersonaPlex output.

Multi-Turn Live Gate

Prove Turn 2 supersedes Turn 1 and stale callbacks cannot release or persist current state.

Compliance Memory Gate

Prove evidence-case/clarify/deflect/answer receipts and fail-closed behavior.

Persistence Gate

Write deterministic conversation turns, retrieval text, source hashes, and audio artifact references.
