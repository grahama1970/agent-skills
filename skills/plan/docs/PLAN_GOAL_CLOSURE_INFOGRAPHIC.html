/plan Goal-Closure Workflow

A deterministic outer loop for plans, with `/orchestrate` and `/code-runner` kept inside their own boundaries.
/plan control /review-plan gate /orchestrate run /code-runner closed/success blocked/human

1. Intent gate: planning is not execution

default

Plan-only request

Create YAML, validate, review, then ask before execution.

0N_TASKS.yaml
The first decision is intent. `/plan` must not silently turn a normal planning request into a task-execution loop.
explicit

Goal-closure request

Only "run until done", "iterate until complete", or `--execute-closure` enters the loop.

--execute-closure --max-replans N

2. `/plan` owns closure and replanning decisions

Validate

Schema, runner routing, code-runner contract, source-apply shape.

plan.py --validate

Review

Claims, skill overlap, blind tests, DoD, forbidden fields.

/review-plan review

Run one session

`/plan` calls `/orchestrate` and waits for the session directory.

session_started
goal achieved?

Stop

Closed.

Assess evidence

Read orchestrate artifacts and emit exactly one closed outcome plus next action.

<plan>.goal-closure.json
Closed outcomes: `goal_achieved`, `partially_achieved`, `blocked`, `wrong_plan`, `insufficient_evidence`.
Closed actions: `none`, `create_followup_plan`, `revise_existing_plan`, `ask_human`.

3. `/orchestrate` runs inside `/plan` and writes proof

Dispatch

Execute the approved DAG with local, scillm, and code-runner workers.

status.json

Evidence stream

Session artifacts become the input to `/plan` closure assessment.

report.txt · events.jsonl

Failure policy

Retries, rollback, and downstream blocking are handled here.

failure-bundle.json

Human escalation

Artifact-first by default. Blocking `/interview` is opt-in.

interview-request.json

4. `/code-runner` is bounded inside `/orchestrate`

Fixed spec

No planning, memory, web tools, or backend racing.

code-runner-spec.json

Worktree

Disposable isolated workspace before source apply.

isolated_worktree

Repair rounds

Limited tools, bounded attempts, visible DoD.

rounds.jsonl

DoD gate

File/process-local command verifies the patch.

verifier.log

Result

Patch artifact or explicit source commit.

result.json

5. `/plan` stops, replans, or asks a human

goal_achieved

Stop. Do not keep looping.

partially_achieved

Create a bounded follow-up stub.

followup-N.yaml

blocked

Ask a human. Do not widen authority.

wrong_plan

Revise before rerun.

insufficient_evidence

Missing proof is not success.

interview-request.json
Invariant: `/plan` supervises closure only by explicit request; `/orchestrate` produces evidence; `/code-runner` never replans or interviews.
