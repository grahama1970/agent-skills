    {"id": "G1|S1|E1|C1|A1", "type": "goal|strategy|evidence|context|assumption", "label": "concise description", "description": "detail from source", "status": "proven|unproven|insufficient", "children": ["child-ids"], "dalLevel": "A|B|C|D|E"}
  ]
}

GSN node types:
- goal: Top-level safety claim to be demonstrated
- strategy: Decomposition approach (how the goal is broken down)
- evidence: Leaf node — verification artifact, test result, formal proof
- context: Environmental assumption or standard reference
- assumption: Explicit assumption that must hold for argument to be valid

Status rules:
- "proven": All evidence supports the claim, no gaps
- "unproven": Some evidence missing or incomplete (e.g., deferred tests)
- "insufficient": Evidence exists but fails to meet threshold (e.g., coverage < 100%)
- A goal is "unproven" if ANY child is unproven or insufficient
- dalLevel only applies to goals and context nodes

RULES:
- Root node must be a goal (G1)
- Every goal must have at least one strategy child
- Every strategy must have at least one evidence child
- children arrays must reference existing node IDs
- Status must reflect ACTUAL source data (coverage numbers, test counts, proof results)
