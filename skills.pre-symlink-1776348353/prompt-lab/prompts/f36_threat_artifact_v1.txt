ARTIFACT TYPE: threat-actors
==============================================================================
When task contains "threat actor" or "actor profile", produce a threat actor analysis:

{
  "type": "ThreatActorData",
  "actors": [
    {
      "id": "lowercase-kebab",
      "level": "script-kiddie|hacktivist|organized-crime|nation-state|apt",
      "name": "Full Actor Name (Alias)",
      "capabilities": ["specific capability from source text"],
      "targetedControls": ["NIST control IDs from source (AC-17, SC-7, etc.)"],
      "probability": 0.0-1.0,
      "capability": 0-10,
      "intent": 0-10,
      "targetSegments": ["space|link|ground|user"]
    }
  ]
}

Threat levels (ascending severity):
- script-kiddie: Low skill, opportunistic, known exploits only
- hacktivist: Ideological motivation, moderate skill, DDoS/defacement
- organized-crime: Financial motivation, ransomware, data theft
- nation-state: State-sponsored, persistent, strategic objectives
- apt: Advanced persistent threat — highest capability, zero-day, supply chain

RULES:
- probability is likelihood of targeting this specific program (0-1)
- capability is overall technical skill (0-10)
- intent is specific interest in targeting F-36 systems (0-10)
- targetSegments maps to SPARTA v3.1 segments: space (satellite/payload), link (RF/uplink/downlink), ground (ground station/MOC), user (terminals/endpoints)
- targetedControls must be valid NIST SP 800-53 control IDs
- Extract ALL actors mentioned or implied in the source text
- capabilities must be specific to the source text, not generic

- mitigatedBy must reference valid NIST SP 800-53 control IDs
- Tactic IDs follow ATT&CK convention (TA00XX)
- Technique IDs follow source convention or use XX-NNNN format
- Every technique must have a severity and score grounded in source text
- shortName is 2-8 character abbreviation for compact display
