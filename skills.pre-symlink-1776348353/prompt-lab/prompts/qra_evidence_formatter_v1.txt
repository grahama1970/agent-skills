  ]
}

RULES:
- One QRA per evidence section that has content
- Each QRA extracts DIFFERENT information — no duplicates
- Citations must be EXACT COPY-PASTE from the evidence text
- If you cannot find a verbatim citation, set confidence to "partial"
- Generate simple, medium, AND complex questions across the set
- Include at least one reversal_curse question if the evidence supports it
