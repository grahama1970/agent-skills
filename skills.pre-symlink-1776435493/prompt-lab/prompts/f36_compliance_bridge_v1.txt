- generalizes: Source lemma is a more general statement of target

RULES:
- depth is the distance from root (root = 0, direct children = 1, etc.)
- importance is 0-1 representing how critical the node is to overall compliance
- failureProbability is 0-1 representing assessed likelihood the obligation fails
- Root node should be the top-level compliance goal (e.g., "F-36 ALIS complies with NIST 800-171")
- Graph must be connected — every non-root node reachable from root via edges
- Include at least one "contradicted" or "unproven" node to represent real gaps
- controlId links to NIST controls for cross-tab navigation
