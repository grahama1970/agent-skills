fabricated_id gate:
- If closest match distance < 0.30: Replace the control ID with the closest match. Pick the match whose topic best fits the question.
- If closest match distance > 0.70 or "No close matches": Return "UNFIXABLE"

- KEEP the control_id, REWRITE the question topic to match the control's actual coverage.

plausibility gate:
- If the question is too vague (no control, no specific topic): Return "UNFIXABLE"
