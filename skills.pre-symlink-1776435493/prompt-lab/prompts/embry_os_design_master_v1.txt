You are designing a new interface component for EMBRY OS, a defense-grade analytical platform for cybersecurity, reverse engineering, and compliance analysis.

## Design System: NVIS MIL-STD-3009

Creative North Star: "Sovereign Observer" — military HUD precision, clean, minimal, high-contrast. Information revealed progressively, never dumped.

### Colors (NON-NEGOTIABLE — do NOT invent new colors)
- green: #00ff88 — Verified, proved, healthy, T0 deterministic
- red: #ff4444 — Error, unverified, failed
- amber: #ffaa00 — Warning, partial, T2 LLM-inferred
- blue: #4a9eff — Info, T1 AST, navigation
- accent: #7c3aed — Primary brand, selected state, interactive focus
- white: #e2e8f0 — Primary text (NOT pure #fff)
- dim: #64748b — Secondary text, labels, metadata
- muted: #334155 — Tertiary text, disabled, placeholders

### Surfaces (Dark Layers)
- bg: #141414 — Primary background
- bgCard: #1a1a1a — Card surfaces
- bgPanel: #111111 — Sidebar, detail panels
- bgDeep: #0b1220 — Code blocks, inputs
- border: rgba(255,255,255,0.13) — Standard border (NEVER opaque white)
- borderHover: rgba(255,255,255,0.25) — Hover state

### Typography (Strictly Assigned)
- Space Grotesk (500-700): Headlines, section titles, branding
- Inter (400-600): Body text, UI labels, navigation
- JetBrains Mono (400-500): ALL code, numbers, hex addresses, parameters

### Scale
- heading: 14px/900 — Section headers
- body: 13px/400 — Body text
- label: 10px/700 — Uppercase labels, tier badges
- code: 11px/400 — Code snippets, method names
- tiny: 9px/700 — Badges, counts

### Rules
1. Progressive disclosure (collapsed by default, expand on demand)
2. Tier badges on extracted data: T0 green DETERMINISTIC, T1 blue AST, T2 amber LLM
3. Tonal layering for depth (NOT drop shadows)
4. No bright borders — use rgba(255,255,255,0.13) max
5. ALL numbers must use JetBrains Mono
6. Desktop only — no mobile considerations
7. No emojis in production UI

## Output Requirements

Generate a complete, self-contained HTML file with inline CSS and realistic placeholder data. The mockup must:
1. Use ONLY the colors, fonts, and tokens above
2. Show all interactive states (default, hover, selected, loading)
3. Include realistic data — not "Lorem ipsum"
4. Be fully functional as a static preview (click handlers optional)
5. Show the complete layout including navigation context
