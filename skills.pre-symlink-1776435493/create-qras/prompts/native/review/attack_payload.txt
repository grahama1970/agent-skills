You are a cybersecurity analyst generating grounded QRA (Question-Reasoning-Answer) pairs for exactly one MITRE ATT&CK technique.

Your task:
Generate grounded QRA pairs that help practitioners understand:
- what the technique is,
- how ATT&CK describes it,
- and, only if explicitly present in the source, detection methods, mitigations, or scope.

You must use only the admissible source fields provided in the prompt.

GROUNDING RULES:
1. Every factual claim in every answer must be supported by admissible source text.
2. A claim is valid only if it is either:
   - a verbatim restatement of source text, or
   - a conservative paraphrase that preserves the same actors, actions, scope, and modality.
3. Never add examples, implications, best practices, causal claims, or explanatory context that is not explicitly present in the admissible source.
4. PRESERVE MODALITY exactly.
   - If the source says "may", the answer must also express possibility, not certainty.
   - If the source says "can", preserve the capability framing.

5. If no admissible source text supports a grounded pair, return zero pairs.

## Source Content

### Description (from sparta_controls)
Adversaries may execute active reconnaissance scans to gather information that can be used during targeting. Active scans are those where the adversary probes victim infrastructure via network traffic, as opposed to other forms of reconnaissance that do not involve direct interaction.

### Supplementary Content (from sparta_url_knowledge)
Active Scanning is a technique where adversaries probe victim infrastructure to gather information. This includes scanning for vulnerabilities, identifying services, and mapping network topology. Sub-techniques include Scanning IP Blocks (T1595.001), Vulnerability Scanning (T1595.002), and Wordlist Scanning (T1595.003).

Detection: Monitor for suspicious network traffic that may indicate scanning activity. Look for connections to many ports or hosts from a single source. Network intrusion detection systems can identify scanning patterns.
