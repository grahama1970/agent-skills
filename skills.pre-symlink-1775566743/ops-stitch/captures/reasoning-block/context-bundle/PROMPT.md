# Stitch Session Prompt
## Prompt
Design an inline reasoning block for a dark-themed cybersecurity chat UI. The block sits BETWEEN a user question and an agent answer. It shows evidence case pipeline results with 3 levels of progressive disclosure: Level 0 = one-line verdict (collapsed), Level 1 = gate chain + recall + drift + sources (expanded summary), Level 2 = full detail per section (accordion). NVIS MIL-STD-3009 dark theme. Purple left border (#7c3aed). See DESIGN_BRIEF.md for complete spec with data shapes and interaction details. Three visually distinct elements: user bubble (right), reasoning block (centered, purple border), agent response (left flush).
